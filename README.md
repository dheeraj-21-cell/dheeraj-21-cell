## 🚀 Featured Project

### 🌍 TripGenie-AI — Personalized Travel Planner

An AI-powered travel planning application that creates personalized multi-day itineraries based on destination, budget, duration, and preferences.

**Key Features**
- 🤖 AI-powered itinerary generation using Groq
- 🌎 Global destination search
- 💰 Itemized travel budget planning
- 🌐 Multilingual interface: English, Hindi, Spanish, and French
- 💾 Save, edit, delete, and manage trips
- 🔄 Regenerate individual days
- ☁️ Supabase cloud storage with SQLite fallback

**Tech Stack:** React · Vite · Python · FastAPI · Groq AI · Supabase · SQLite
